# Phase 14 实现与验收报告

交付日期：2026-10-22。设计源为 [Phase14_GAMEPLAY _Redesign.md](<Phase14_GAMEPLAY _Redesign.md>)。本次已完成**可玩的地图—战斗—事件—构筑—切出主循环及数据结构迁移**；不将原型数值和自动模拟声称为最终平衡或真人体验验收。

## Changed

- 永久 DeckState 与 CombatDeckState 分离；战斗 AP/Block/Intel/Noise 从长期玩家域剥离。
- PlayerState 聚合真实长期知识集合、永久牌组和三格装备。RunState 聚合当前 Level、历史、流程与单场战斗。
- 建立有限效果/状态/条件/弱点/行为配置；实体公开锁定意图，UI 与执行读取同一确定效果。
- 统一 1 AP 撤离；HP 随机范围由实体及当前意图决定；存活为 ESCAPE，致死为 DEFEAT，无胜利奖励、不换层。
- 非线性分层 DAG、内容迷雾、一次性节点、文本事件、奖励、REST、SHOP、EXIT 全部接入正式 Main。
- 概率 CutOut、已访问降权、已生成楼层原图入口重返；已结算节点只通行、不刷收益。
- 每个玩家动作进入 GameCommand → RuleResolver；计划不写权威状态，完整提交后才通知 UI。
- 退场前先合并原实体最终 HP/死亡/退去和战斗结局，再释放活动引用；旧实例不会仍显示存活。
- 补充关键所有权/生命周期中文注释，更新当前约束与迁移文档。

## Architecture

完整状态树、唯一提交者、回合顺序和数据合同见 [当前架构](PHASE_14_ARCHITECTURE.md)；旧字段映射和审查结果见 [迁移记录](PHASE_14_MIGRATION.md)。

关键边界：

- Plan 使用私有战斗草案与隔离 RNG，成功才按域合并；Result 捕获原 Run 与 revision，不能重复或跨局提交。
- 卡牌/敌人/物品实例身份独立，静态 Resource 不存可变生命、次数或层数。
- 意图先锁定，Noise/增益影响下次锁定；防护/失衡仍可干预本次结果。
- 长期 Knowledge 分类去重；战斗 Intel 可消费，二者没有合并。
- MAP/EVENT/REST/SHOP 不发整套战斗手牌，也不消耗不存在的探索 AP。

## Behavior

正常开局：零层地图 → 选择绿色后继 → 文本事件、战斗、交易、补给或休息 → 节点结算 → 地图 → EXIT → 目的地概率 → 六层 → 遭遇与构筑 → EXIT → M.E.G. 撤收总结。

普通 CutOut 不判失败；可能返回已访问 Level，但权重乘 0.15。知识/物品修正通过 Resource 声明。重返恢复同一 FloorState/MapState，落在入口；所有历史节点信息和一次性结算保留。即使全图已结算、装备耗尽、没有知识，也可通行到出口。

Smiler 使用共同实体 HP，反复真实强光触发躁动；持续黑暗可在第二回合末存活退去并确认唯一规律。事件提供同规律替代路线。当前只实际支持一个敌人，不伪装完成多敌人系统。

## Manual Playtest

1. F5 开局应直接看到零层地图；连接可见，远处问号隐藏内容，绿色为合法后继。
2. 选择事件；尝试资源不足的选项应置灰/拒绝，免费离开始终可用。记录知识后看揭示范围或出口身份变化。
3. 进入战斗，确认 AP 3、五张基础牌、至多一张装备机会；侦察获得 Intel，再打精确打击/预判等。
4. 观察公开意图，打一张防护再结束回合；核对防护抵伤、状态到期及下一意图。
5. 在剩余 1 AP 时查看撤离 HP 区间并撤离，回到当前 Level 地图，不出现本场胜利奖励。AP 0 时撤离不可执行。
6. 胜利领取三选一；在后续战斗抽到新增牌。REST 查看升级/删除候选再返回，不消费；最终确认只结算一次。SHOP 可交易一次或离开。
7. 手电开启/熄灭为真实不同牌；成功才扣电。笑魇遇强光躁动，保持黑暗可存活退去；未必每种子都出现笑魇。
8. 到 EXIT 查看已知/未知目的地概率与生效修正，确认切出；切入六层后装备/长期牌/知识保留，战斗资源重置。
9. 若随机返回旧 Level，应看到原图已访问记录，入口起步、已结算节点仅经过；继续到出口。
10. 六层切出至撤收点后查看总结并开始新局。三种分辨率重复地图/手牌/撤离按钮检查。

## Known Limitations

- 单敌人、Level 0/6、M.E.G. 原型；没有多职业、多敌人、Boss、元进度、制作或复杂环境模拟。
- 历史楼层只在本局内存中保存，没有磁盘存档/旧存档迁移。
- SHOP 为单次交易，REST 为单次整备；没有复杂库存/商店刷新/多格装备。
- 特殊状态首版是有限平坦规则，不是完整伤害公式；知识类别和实体原型仍可随内容细化。
- 新内容共 69 个视觉 ID，升级共图后仍缺 **51 张专用插画**（P0 2 / P1 49）；默认图不代表专用美术完成。事件当前以文本呈现，插画映射预留而未谎称已绘制。详见 [素材表](PHASE_14_ASSETS.md)。
- 音频静音、中文系统字体；没有实际听测、导出包或额外平台验证。
- 初始卡池、奖励/HP/压力数字尚需真人测试；上述自动模拟不能替代最终平衡。
