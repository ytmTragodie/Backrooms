本阶段是 Phase 14 的增量扩展。保留 MAP → 节点遭遇 → 结算 → MAP、单敌人、真实手牌、统一事务和楼层历史。Status 只分析，不迁移。用户确认：末端为零代价/代价出口，不是条件出口。

## 已实施的四阶段

1. 基础随机 DAG → 配置规则修正 → 最终图与内容验证。
2. 从实际 FloorData/CutOutRouteData 派生只读楼层网络，记录发现/访问/穿越。

## 地图生成规则

MapRuleData 只有四种有限规则，不解释表达式：

| 类型 | 用途 |
| --- | --- |
| PLACE_CONTENT | 在指定层区间放置少量代表性遭遇锚点 |
| INTEL_BEFORE | 在真实祖先路径的 2–3 步处放置情报事件 |
| SUPPORT_AFTER | 在真实直接后继放休息或指定高价值奖励 |
| LIMIT_DANGER | 限制任意路径连续战斗/精英数量 |

`required` 表示必须满足；否则按 probability 采用，缺乏合适位置时允许跳过。`max_applications` 限制放置量。关联规则可用 `anchor_rule_id` 锁定已放置的实例，不能被同定义的随机副本抢占。

必经情报通过真实图支配关系验证：从 entry 到目标的任何路径都经过线索。生成器沿既有路径收束目标来路，并给受影响侧枝补前向后继；不根据节点编号或屏幕坐标判断。目标所在路线仍可被玩家绕开。“必经事件”不强迫阅读：玩家仍可选不作停留。

七层：第 4 层放置巨影代表节点；2–3 步前的笔记对它必经；直接后继有 6 补给奖励。另有 45% 概率情报；它不保证每次出现。零层连续危险强约束 2，六/七层强约束 3、80% 的地图优先限制到 2，保留少量高风险布局。数值均为可编辑原型配置。

区域仅通过 Resource 配置权重与所属池的 ID：七层 1–2 为房屋，3–6 为海洋。未建立移动速度、潜水计时或实体巡逻状态。未来动态遭遇可引用稳定节点 ID，不能改写静态定义存运行时实体。

生成使用传入的私有 RNG，有限次修正，不靠无界重试。最终校验唯一 ID、合法引用、前向无环、入口可达、每节点可达某个出口、硬规则、内容池和必经关系。无效新局草案不替换现有 RunState；无效切出目标地图使整个 ActionResult 失败。

末层零层 3 个出口、六层 3 个出口、七层 2 个出口。池超出容量时保留第一条基准路线，再按种子抽取互不重复的剩余路线。因此六层潮声阶梯是可能出现的路线，不保证每张地图都出现；同一局重返不会重抽缺失路线。

## CutOut：条件与代价的区别

- 出口不设可操作性条件。每条路线必须有一个入口也无条件的正权重候选。
- 额外候选可要求 Knowledge、尚可使用的装备或某楼层已经提交的事件选项。条件只筛选候选；不消耗知识/装备，不隐含开锁动作。
- 入口为 FloorEntranceData。当前所有命名入口都落在原图 `entry`；七层明确为房屋客厅，不新增中途传送落点。
- 出口公开 hp_cost / stress_cost。原有出口零代价；七层洞穴边缘撤收绳为生命 3、压力 2。代价不引入成功率。
- 生存足够则按筛选、重访降权、知识/装备修正后的最终权重抽取，普通 CutOut 必定成功。
- 生命不足仍可执行：确认前明确警告，提交生命归零和 RESULT，不留下软锁，也不抽目的地 RNG。这是代价导致本局失败，不是假装切出成功。
- 预览和大地图共用纯 distribution，均不接触 RNG；未公开目标合并为“未知目的地”。网络远程概率标成当前持有条件估计，到实际出口时重算。
- 全楼层静态可达撤收点验证只使用**无条件连接**，不能借一个可能永远达不到的条件来伪造可达性。

目标连接从仅 `floor_id` 改为独立 `id + floor_id + entrance_id`；旧 modifier 同次迁移到连接 ID，不保留新旧双匹配。新/旧资源都走同一 CutOutSystem。

## 事务顺序

命令实例上下文/版本/阶段验证 → 复制 RNG → 计算候选和完整代价 → 抽目的地 → 取得原历史图或生成并验证私有目标图 → 分域 ActionResult → 原有 Commit。

提交按 Player（含知识事实）、Card、Equipment、Map（先旧节点与事件选项，再换层/访问计数）、Combat、Flow、RNG/revision、Notify。失败不消费生命、压力、装备、卡、地图、知识或随机序列。重返保持节点/事件结果/奖励记录，仅回入口，已结算节点只通行。

## 七层内容与来源

七层采用用户提供的房屋/海洋版本为主要依据：客厅落点、渗水浴室、儿童房、研究记录、海底骸骨、洞穴和防火门。新增 7 个七层事件、1 个共用 EntityInstance 的巨影、两条实际出口；另有零层爪痕线索、六层潮声事件。共 9 个新事件。

巨影使用 90 HP、减伤 2、公开撞击意图。强光通过既有 TriggerData/WeaknessData/EffectData 令其活着退去；没有按实体 ID 的脚本分支。笔记和行为均可确认同一个 `abyss_light` 知识。它是原型遭遇，不实现完整海洋生态或 Boss。

## 后续边界

没有加入 Boss、多敌人、额外新楼层、巡逻追猎、磁盘存档、装备修理、Status 重构或泛化事件 DSL。`FloorHistoryState` 的持久仍限同一局内存。生成配对不保证奖励路线唯一：战后补给是可选择的后继，不强迫玩家领取。
