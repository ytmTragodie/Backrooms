## 给美术/素材收集者的操作说明

1. 按表放入 backgrounds、cards、entities、ui、fx、audio 的预定位置；不要放入 scripts 或 data。
2. 插画优先 PNG；背景允许 JPG（更改 JSON 路径）；环境音优先 OGG，短音效可用 WAV（同步路径）。
3. 背景 16:9；牌面 2:3；图标正方形。文字由 UI 排版，插画不烘焙标题和数值。
4. 文件名使用英文 snake_case，与稳定 ID 对齐；路径大小写一致，禁止本机绝对路径。
5. 牌框、图标、立绘及 FX 要透明；背景和普通插画不要求透明。
6. 将文件放入表中精确路径，或仅修改 JSON 的 path；Godot 自动导入后重新运行。检查画面和 Phase 11 素材测试，确认 AssetCatalog.is_provided(ID) 为真，再将清单状态改为 PROVIDED。
7. 优先顺序：两层背景 → 猎犬/笑魇与目标插画 → 玩家牌/事件牌 → 四种牌框 → 图标 → 预警音/环境音 → 可选特效。

音频播放器与纹理加载均使用同一清单，缺失不会阻止玩法；更换素材不需要修改规则代码。
